Questions fréquentes

Comment créer un compte ?

Clique sur Compte puis inscris-toi avec une adresse e-mail, un numéro de téléphone et un mot de passe.

Est-ce que Gmail fonctionne ?

Oui. Gmail est simplement une adresse e-mail.

Comment fonctionne le panier ?

Ajoute les produits au panier puis ouvre le panier pour modifier les quantités ou commencer la commande.

Comment fonctionne le code promo ?

Les codes disponibles dans cette version sont des codes de démonstration. Le code NOVA100 permet de simuler une commande gratuite.
