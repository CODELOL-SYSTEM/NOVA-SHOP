❓ Questions fréquentes

Comment passer une commande ? ＋
Ajoute tes produits au panier, renseigne ton adresse, puis passe à l'étape de paiement.
Comment utiliser un code promo ? ＋
Entre ton code dans la section « Code promo » puis appuie sur « Appliquer ».
Où voir mes commandes ? ＋
Connecte-toi à ton compte puis ouvre la section « Mes commandes ».
Comment demander un remboursement ? ＋
Ouvre une commande depuis ton espace client puis utilise le bouton « Remboursement ».
Puis-je payer par carte, PayPal ou Revolut ? ＋
L'interface peut proposer ces méthodes. Pour accepter de vrais paiements, chaque méthode doit être reliée à son service de paiement officiel côté serveur.
